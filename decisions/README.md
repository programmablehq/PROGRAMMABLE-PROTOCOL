# Decision records

Decision records explain why material protocol choices were made. The current
numbered specification is normative if historical wording and current meaning
ever differ.

Statuses are Proposed, Accepted, Superseded, Rejected, or Withdrawn. Every
material record uses the sections required by [`CONTRIBUTING.md`](../CONTRIBUTING.md).
After an accepted record first appears in a tagged Protocol release, it is
append-only: factual corrections use dated errata, and a later choice uses a
new record that names the record it supersedes. Before first inclusion in a
tagged release, maintainers may complete required sections or clarify prose
without changing the recorded decision.
