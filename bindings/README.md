# Native binding documents

- Status: Draft
- Classification: Normative index
- Scope: Cross-runtime
- Spec ID: `programmable-protocol/0.1.0-draft.1`

[`evm.md`](evm.md) and [`svm.md`](svm.md) map portable requirements to their
native runtimes. They do not define a shared ABI, byte layout, state store, or
custody mechanism.

A binding document states requirements. The corresponding implementation
repository owns source code, generated native interfaces, runtime tests,
artifacts, and deployment manifests.
