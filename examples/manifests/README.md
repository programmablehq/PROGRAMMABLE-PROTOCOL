# Manifest shape examples

These documents are schema-valid non-production examples. Their addresses,
commits, digests, transactions, ledger positions, and evidence records are
deliberate placeholders. They are not deployment evidence and must not be used
as a release pin.

The examples demonstrate the distinct Ethereum Virtual Machine and Solana
Virtual Machine branches of the deployment-manifest schema, including separate
portable, binding-native, and Asset Profile conformance pins. A real manifest
must replace every placeholder path and digest with evidence from one exact
build and live deployment and must pass the independent verification described in
[`../../spec/05-versioning.md`](../../spec/05-versioning.md).
